# Estructura del Sitio Web - Yamgurumi

Este documento define la estructura de páginas planificada para el sitio web.

## Páginas Principales (Solicitadas)

1. **Home (Inicio)**: La página principal (Landing Page) con el Hero 3D, categorías destacadas, y propuesta de valor.
2. **Catálogo de Amigurumis**: La tienda completa donde se pueden filtrar y explorar todos los amigurumis disponibles (por precio, tamaño, temática).
3. **Detalle de Producto**: Página específica para cada amigurumi con galería de fotos, detalles del hilo/materiales, historia del personaje y botón de añadir al carrito.
4. **Checkout Artesanal**: El flujo de pago adaptado a la temática, con detalles de envío y métodos de pago seguros.
5. **Nuestra Historia**: Una página sobre la artesana/creadora, el proceso de tejido a mano, y el valor del trabajo artesanal.
6. **Tu Estudio (Perfil)**: El panel de control del usuario donde puede ver su historial de pedidos, guardar sus amigurumis favoritos (wishlist) y editar su información.
7. **Error 404 (¡Ups!)**: Página de "No encontrado" personalizada con algún amigurumi enredado o perdido para mantener la temática.

---

## Páginas Adicionales Sugeridas (Recomendadas para E-commerce)

Para que la tienda sea completa, profesional y genere confianza, recomiendo agregar las siguientes páginas:

8. **Cuidado de tu Amigurumi**: Una guía sobre cómo lavar, secar y cuidar los muñecos tejidos para que duren toda la vida (muy importante para productos artesanales).
9. **Preguntas Frecuentes (FAQ)**: Respuestas a dudas comunes sobre tiempos de elaboración, envíos internacionales, materiales hipoalergénicos, etc.
10. **Contacto**: Un formulario simple para consultas, comisiones especiales, o problemas con pedidos.
11. **Pedidos Personalizados / Comisiones**: Una página dedicada exclusivamente a explicar cómo el cliente puede pedir un amigurumi personalizado (con un formulario especial).
12. **Carrito de Compras (Cart)**: Página o Drawer lateral para revisar los productos antes de pasar al Checkout.
13. **Seguimiento de Envío**: Página donde el cliente puede poner su número de guía para saber dónde está su paquete.

## Páginas Legales (Necesarias)
14. **Términos y Condiciones**: Reglas de uso del sitio web.
15. **Política de Privacidad**: Cómo se manejan los datos del usuario (obligatorio para pasarelas de pago).
16. **Política de Envíos y Devoluciones**: Reglas claras sobre tiempos de entrega y qué hacer si un producto llega dañado (vital para evitar malentendidos en artesanías).
